# Leadfy

Sistema de CRM de vendas voltado para gestão de leads, oportunidades comerciais e apoio estratégico ao processo de conversão.

## Visão Geral

A aplicação frontend de Leadfy é responsável pela interface de gestão comercial do CRM, permitindo o gerenciamento de leads, usuários, produtos e oportunidades de venda, além de funcionalidades com inteligência artificial para geração de planos de ação comerciais.

## Arquitetura Frontend

A estrutura do projeto frontend está organizada de forma modular para facilitar manutenção, escalabilidade e reutilização de componentes.

```text
src/
├── assets/       # Arquivos estáticos (imagens, logos)
├── components/   # Componentes reutilizáveis da interface
├── pages/        # Páginas correspondentes às funcionalidades do sistema
├── routes/       # Configuração e gerenciamento de rotas da aplicação
├── services/     # Comunicação com APIs e serviços externos
├── utils/        # Funções utilitárias puras e reutilizáveis
```
