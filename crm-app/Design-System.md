# Regras

- Sidebar sempre verde escuro.
- Topbar sempre branca.
- Background principal sempre claro.
- Apenas ações principais usam verde.
- Azul reservado para ações neutras/editáveis.
- Vermelho apenas para ações destrutivas.
- Laranja apenas para estados de atenção.
- Hover obrigatório em todos os elementos interativos.
- Bordas sempre discretas e neutras.
- Priorizar contraste e legibilidade.
